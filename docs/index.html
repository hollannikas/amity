Threads of Amity

Original 8-bit DMG Game Boy RPG built with RGBDS SM83 assembly

Default Controls

D-Pad
Arrow Keys — Move / Navigate menus
A Button
Z or X (configurable in toolbar) — Talk / Confirm / Equip
B Button
X or Z — Cancel / Close Inventory / Run
Start
Enter — Start game / Trigger encounter
Select
Right Shift — Open / Close 4×2 Inventory
